# About seedypod

A Gardyn is a good piece of hardware: a vertical hydroponic tower with a grow light, a pump, sensors and two cameras, run by a Raspberry Pi. It also has a cloud subscription in front of it. seedypod replaces the cloud with open-source software you run on the Pi that is already there, so the tower keeps working on your terms.

The name follows [sleepypod](https://sleepypod.github.io/), the sibling project that does the same for Eight Sleep Pods, and Gardyn's plant slots are literally called pods: you put seeds in them. The project was drafted as **leafypod** and renamed to seedypod when it moved to the `seedypod` GitHub organization.

## Project status

What exists today:

- The Rust hardware daemon `hald`, with its safety guard, simulator, MQTT and Home Assistant discovery, and drivers for every documented part, cross-built for the Pi Zero W and the Zero 2 W, Pi 4 and Pi 5.
- Core: the tRPC, REST, MCP and WebSocket server, SQLite store, light curves and bounded pump cycles, grow cycle and reminders, 30-pod tracking, camera captures with per-pod growth trends, the Home Assistant bridge, an optional API key, the web UI and the browser demo.

The software is built and tested against a simulator, and since November 6, 2026 it has run on a real Gardyn 3.0 with its original Pi Zero W. On that unit the install scripts and seedypod OS, the grow light, the I²C sensors, both cameras with image analysis, HomeKit pairing and the web UI are verified; the [hardware map](/developers/hardware/) has the per-pin status.

What comes next: the unit's tank is still empty, so a pump run, the pump-power calibration and the water level against water are unverified, and so is the button. The cameras' USB hub comes up on only some boots, which is still being traced. The [handoff](/developers/handoff/) has the details.

## Credits and license

seedypod is licensed under [AGPL-3.0](https://github.com/seedypod/core/blob/a2f6b4c98085d6729f8c2f315237f87f759518e2/LICENSE), the same as [sleepypod](https://sleepypod.github.io/about/).

It is a clean-room implementation: no code from [iot-root/garden-of-eden](https://github.com/iot-root/garden-of-eden) (GPL-3.0) is used. That project's pin map and issue history were invaluable references; its known failure modes became seedypod's safety test cases. See [ADR 0002](/developers/adr/0002-license/).

Questions, ideas and grow logs are welcome in the seedypod channel on sleepypod's [Discord](https://discord.gg/UMmv5R6MXa).

seedypod is independent, community-built software. It is not affiliated with or endorsed by Gardyn.
