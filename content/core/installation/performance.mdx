# Measured on a Pi Zero W

These are observations from the November 6, 2026 bring-up of one Gardyn 3.0 with a **Pi Zero W Rev 1.1**, a 64 GB card and Wi-Fi. They are not multi-device benchmarks; a Zero 2 W has not been timed.

| Measurement               | Earlier bring-up                                            | After the changes                                         |
| ------------------------- | ----------------------------------------------------------- | --------------------------------------------------------- |
| New-card setup            | About an hour using the scripts with a local SQLite compile | Image: web app serving **4m31s after power-on**           |
| Core update               | 6m13s                                                       | **1m24s**                                                 |
| Reboot to web app serving | About 4 minutes                                             | **About 2.5 minutes**                                     |
| Card writes, daily rate   | About 440 MB/day                                            | **About 63 MB/day**, extrapolated from a 20-minute sample |
| Core at idle              | 6.4% CPU, 90 MB RAM                                         | **3.4% CPU, 109 MB RAM**                                  |

The image timing excludes downloading and writing the card. SSH became available later, at about **7.5 minutes** on first boot; web access does not need SSH. A fresh script install using the prebuilt SQLite binary has not been timed separately. The write rate is a short observation, not a card-lifetime estimate, and the lower idle CPU came with higher memory use.

## The [bring-up record](https://github.com/seedypod/core/blob/e6d5f76db6af428750724fc73546d86d147c4637/docs/HANDOFF.md#measured) contains the measurements and hardware limits. Camera USB-hub enumeration remains under investigation; these web-start timings do not establish that every peripheral is ready. The longer boot comparison is still in progress.
